# Fotos do site

Coloque aqui as fotos **originais** da RoadTrip021. O build gera automaticamente
versões otimizadas (AVIF/WebP, vários tamanhos) — não é preciso redimensionar antes.

Enquanto um arquivo não existir, o site mostra um espaço reservado com a etiqueta
"Foto pendente" e o nome esperado do arquivo.

## Nomes esperados

Use exatamente estes nomes (extensão `.jpg`, `.jpeg`, `.png`, `.webp` ou `.avif`):

| Arquivo | Onde aparece | Recomendação |
| --- | --- | --- |
| `hero.jpg` | Topo da página (imagem principal) | Horizontal, grupo em viagem, mín. 2400 px de largura |
| `bahia.jpg` | Destino Expedição Bahia + saídas da Bahia | Vertical ou quadrada, mín. 1200 px |
| `uyuni-atacama.jpg` | Destino Salar de Uyuni + Atacama + saídas | idem |
| `jalapao.jpg` | Destino Expedição Jalapão | idem |
| `atacama.jpg` | Destino Deserto do Atacama | idem |
| `lencois-maranhenses.jpg` | Destino Lençóis Maranhenses | idem |
| `machu-picchu.jpg` | Destino Machu Picchu | idem |
| `amazonia.jpg` | Destino Amazônia + saídas da Amazônia | idem |
| `chapada-diamantina.jpg` | Destino Chapada Diamantina | idem |
| `sao-thome-das-letras.jpg` | Destino São Thomé das Letras + STL Festival | idem |
| `ibitipoca.jpg` | Destino Ibitipoca | idem |
| `sobre-1.jpg`, `sobre-2.jpg`, `sobre-3.jpg` | Seção "Sobre a RoadTrip021" | Fotos de grupos reais, mín. 1000 px |
| `instagram-1.jpg` … `instagram-6.jpg` | Seção Instagram | Quadradas, mín. 800 px |

## Dicas

- Prefira fotos reais de grupos da RoadTrip021 (pessoas + paisagem).
- Evite fotos com texto/arte por cima (o site já aplica o texto).
- Ao incluir uma foto, atualize o texto alternativo (descrição) em `src/data/`
  (`destinations.ts`, `gallery.ts`) ou no componente da seção.
