# Logo

Salve aqui o arquivo oficial do logo da RoadTrip021 com o nome **`logo.svg`**
(ou `logo.png` / `logo.webp`, fundo transparente).

Assim que o arquivo existir, ele substitui automaticamente o logotipo tipográfico
provisório usado no cabeçalho, no menu mobile e no rodapé.

Observação: o cabeçalho e o rodapé usam fundo escuro em alguns momentos — o ideal é
uma versão do logo que funcione sobre fundo escuro (ex.: logo claro) ou um SVG que use
`currentColor`.
